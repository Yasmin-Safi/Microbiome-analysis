

## Overview

This repository contains the analysis workflow for a longitudinal gut microbiome study in patients with locally advanced rectal cancer (LARC). Stool samples were collected at three study time points:

- **S1:** Baseline
- **S2:** After radiotherapy
- **S3:** After chemotherapy

The project examines gut microbial profiles across treatment time points using 16S rRNA gene amplicon sequencing data and downstream statistical analyses.


## Study and sequencing workflow

### Sequencing and laboratory processing

According to the sequencing laboratory documentation, the target region was the V3–V4 region of the 16S rRNA gene, using the primer set labelled **Bakt_341F–805R**.

The laboratory's detailed protocol describes the following processing steps:

1. Removal of adapter and primer sequences using Cutadapt v3.2.
2. Trimming of forward and reverse reads to 250 bp and 200 bp, respectively.
3. Quality filtering and denoising with DADA2 v1.18.0. Reads with expected errors of 2 or more were excluded.
4. Merging of paired-end reads by overlap.
5. Chimera removal using the consensus method in DADA2.
6. Removal of ASVs shorter than 350 bp.
7. Taxonomic assignment against the NCBI 16S reference database.
8. Downstream community analyses described by the laboratory as using QIIME.


### Analysis dataset

The downstream statistical analyses were performed by the study team using the final taxonomic count table supplied by the laboratory. The table reportedly contains **167 samples** across S1, S2, and S3 and **805 species-level taxonomic labels**.

Species-level labels from 16S V3–V4 amplicons may not always distinguish closely related bacterial species reliably. Interpret species-level results as taxonomic assignments rather than definitive species identification unless resolution has been independently validated.

## Analysis objectives

The analysis focuses on longitudinal comparisons of gut microbial profiles across S1, S2, and S3, including:

- Alpha diversity and within-sample richness.
- Beta diversity and differences in community composition.
- Taxon-level abundance patterns across time points.
- Prevalence and presence/absence patterns.
- Sensitivity analyses at genus level where supported by the available taxonomic table.
- Assessment of how differences in sequencing depth and incomplete follow-up may affect interpretation.


## Data processing and normalization

Relative abundance tables may be generated by **total sum scaling (TSS)**, dividing each taxon's count by the total count in its sample. These values sum to 1 within each sample.

Count tables should be retained separately for analyses that require counts. For richness and presence/absence sensitivity analyses, the study workflow describes rarefaction to **7,500 reads per sample**, using the mean of 20 independent rarefactions (50 for prevalence analyses). The reported minimum sample count was 7,560 reads.

Before reproducing these analyses, verify that the read counts used for rarefaction are from the same final table used in the statistical analyses and that the rarefaction procedure is implemented as described in the analysis scripts.
